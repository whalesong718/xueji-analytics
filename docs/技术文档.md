## 二、统计算法层 (stats_engine.py)

### 单次作业统计 compute_homework_stats()

- 正确率 = 正确 / (正确 + 错误)，空题不计入分母
- 完成率 = (正确 + 错误) / 总题数
- 难题正确率 = 难题正确 / 难题已答
- 错误分布：5类错误各出现几次

### 时间序列统计 compute_series_stats()

- **移动平均**：窗口 5 次（近一周）
- **EWMA**：α=0.3，指数加权
- **趋势斜率**：最小二乘法线性回归
- **稳定性**：方差（越小越稳定）
- **连续改善/退步**：从末尾向前数连续升降次数

### 错误模式统计 compute_error_pattern_stats()

- **重复率**：近5次总错误次数 / 5
- **出现次数**：近5次中有几次>0
- **周对比**：上周(前5次) vs 本周(后5次)
- **自纠率**：错误出现后，下次作业该错误减少的比例

### 趋势判定 determine_trend()

- 斜率 > 0.01 → improving
- 斜率 < -0.01 → declining
- 方差 > 0.02 → 附加 volatile 标记

## 三、BKT 掌握度模型 (bkt_engine.py)

### 原理

Bayesian Knowledge Tracing 追踪每类错误的"未掌握概率" P(~L)。

四参数：

| 参数 | 含义 | 默认值 |
|------|------|--------|
| L0 | 初始掌握概率 | 0.1 |
| T | 学习率（犯错后掌握概率） | 0.3 |
| G | 猜测率（未掌握却答对） | 0.1 |
| S | 失误率（已掌握却答错） | 0.15 |

### 特殊设计

- **遗忘衰减**：每天 5% 的概率遗忘（P(~L) 退回到 0.5）
- **交替学习效应**：同一类错误连续出现时，学习率从 0.3 衰减到 0.1
- **按错误类型追踪**，不是按知识点——更鲁棒、数据更容易收集

### 掌握度等级

| 掌握度 | 等级 |
|--------|------|
| ≥ 0.8 | 已掌握 masterd |
| ≥ 0.6 | 基本掌握 developing |
| ≥ 0.4 | 初步掌握 emerging |
| < 0.4 | 薄弱 weak |

## 四、规则引擎 (rules_engine.py)

### 规则列表

| 编号 | 名称 | 触发条件 | 置信度 |
|------|------|---------|--------|
| R001 | 持续进步 | 斜率 > 0.01 且连续改善 ≥ 2 | high |
| R002 | 反复犯错 | 重复率 ≥ 0.6 且出现 ≥ 3 次 | high |
| R003 | 问题已解决 | 上周>0 本周=0 且掌握度>0.6 | high |
| R004 | 新出现问题 | 本周>0 且之前从未出现 | medium |
| R005 | 难题放弃 | 近5次中≥2次难题空题≥2 | high |
| R006 | 进步停滞 | 掌握度<0.5 且观察≥5次 | medium |
| R007 | 计算改善 | 计算失误连续减少≥2周 | high |
| R008 | 退步预警 | 斜率 < -0.02 且连续下降≥2 | high |

### 规则优先级

正面（R001/R003/R007）> 负面（R002/R004/R005/R006/R008）

## 五、报告生成层 (report_generator.py)

### ReportGenerator

接收 Phase 1 + Phase 2 的所有输出，生成 6 个章节：

1. **概览卡片** — 正确率、趋势、掌握度概要
2. **BKT掌握度分析** — 5类错误详细掌握度 + 趋势
3. **错误分析** — 本周 vs 上周对比，严重程度标签
4. **规则结论** — 触发的规则及置信度
5. **学习建议** — 针对薄弱环节的精准建议
6. **下周计划** — 周一至周日每日安排

### 输出格式

- `format_text()` → 纯文本（终端友好）
- `to_dict()` → 结构化 JSON（可存储/可推送）
- `raw_weekly_report` → 兼容 `data_models.WeeklyReport`
